Recording is not wired up yet.

For a web target, or an embedded web view with a debugging port, recording means injecting a picker into the page and capturing several candidate strategies per element. For a native window with no such port, it means Win32 hooks plus a UIAutomation lookup at the click point — and, where UIA sees nothing, cropping an anchor image from a screenshot.

Which of those to build is decided by tools/probe_native.py, which has not been run against the target application yet. Until then, + Record creates a flow from a working template for you to edit here.
